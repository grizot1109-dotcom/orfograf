# Орфограф

Тренажёр русского языка: карта тем, короткие уроки по 10 карточек, интервальное повторение, блиц, дуэли и недельный рейтинг с друзьями. Брат «Формулографа».

Открыть: https://grizot1109-dotcom.github.io/orfograf/

На iPhone: открой ссылку в Safari → «Поделиться» → «На экран Домой».

## Что внутри

- **Учиться** — маршрут из 18 тем в порядке заданий ЕГЭ (№4–21): ударения, паронимы, формы слов, грамматические ошибки, словарные слова, проверяемые гласные, чередования, О/Ё, приставки, Ъ и Ь, суффиксы, окончания глаголов, НЕ и НИ, слитно/дефис, Н/НН, запятые, тире. Все темы открыты сразу, у каждой есть теория: правила, таблицы, исключения, ловушки.
- **Повторить** — карточки с ошибками возвращаются через 10 минут, выученные — через 1, 3, 7, 16 дней. Блиц 60 секунд и дуэль вдвоём на одном телефоне.
- **Друзья** — рейтинг за день, неделю и месяц, онлайн-дуэли по ссылке, лента.
- **Статистика** — точность по темам, слабые слова, активность за 14 дней, последние ошибки.
- **Профиль** — уровень, 30 медалей (до 5 в профиле), рамки и фоны за уровни и медали, оформления приложения, фото и статус.

## Откуда задания

- Ударения — полностью по «Орфоэпическому списку — 2026» ФИПИ (задание 4 ЕГЭ).
- Паронимы — пары из «Списка паронимов — 2026» ФИПИ (задание 5).
- Словарные слова, корни с чередованием и особые слова, слова для заданий 10–14, наречия для задания 14, словарные и типовые примеры — по «Навигатору подготовки к ЕГЭ 2026» ФИПИ (разделы «Орфография» и «Грамматика. Синтаксис»).
- Грамматические ошибки (задание 8) — все предложения из открытого банка заданий ФИПИ (73 задания, без повторов 500+ предложений) и демоверсий 2022–2027: в каждом указан тип ошибки и исправленный вариант.
- Орфография сверена со словарём ru_RU (LibreOffice/Hunspell). Запятые, НЕ и слитное/раздельное написание проверены вручную по правилам.

## Файлы

- `index.html` — оболочка и стили
- `app.js` — логика приложения
- `data.js` — банк заданий и короткие правила, `theory.js` — теория, `medals.js` — медали, `cosmetics.js` — рамки и фоны, `skins.js` — оформления.
- `data.js`: Формат описан в начале файла: добавить слово = добавить строку.
- `sw.js`, `manifest.webmanifest` — работа без интернета и установка на экран
- `supabase.sql` — таблицы рейтинга и дуэлей

## Рейтинг

Хранится в том же проекте Supabase, что и «Формулограф», в таблицах `ru_scores`, `ru_duels`, `ru_duel_results`. Игроки общие: ник и фото берутся из «Формулографа», если он открывался на этом телефоне. Чтобы развернуть с нуля, сначала выполни SQL «Формулографа», потом `supabase.sql`.
